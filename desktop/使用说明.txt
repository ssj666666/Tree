Tree 桌面版（Windows）使用说明
================================

这是什么？
----------
Tree 桌面版就是把 Tree 的网页版装进一个独立窗口。
Tree 本体一直在你的阿里云服务器上 24 小时运行，你的电脑关机它也
照常工作；这个 App 只是用来和它聊天的窗口。

安装（3 步）
----------
1. 把压缩包里的 Tree-1.0.0-win64 文件夹解压到你想放的位置
   （比如 D:\Tree），不要放在临时文件夹里。
2. 双击里面的 Tree.exe 打开。
3. 第一次打开会显示 Tree 的登录页，和浏览器里一样输入账号
   （用户名 tree）和你设好的密码登录。

   注意：Windows 可能会弹一个蓝色提示“Windows 已保护你的电脑”
   （因为这个程序没有花钱做签名认证），点“更多信息”，再点
   “仍要运行”就可以了。程序本身是你自己的，没有病毒。

日常使用
--------
- 按 Ctrl+Alt+T：随时显示 / 隐藏 Tree 窗口。
- 点窗口右上角的 ×：窗口会藏到右下角托盘里，不会退出；
  双击托盘里的小树图标可以再把它叫出来。
- 窗口藏起来的时候，如果机器人回了新消息，右下角会弹通知，
  点一下通知就回到窗口。
- 托盘图标点右键：显示 / 隐藏 / 重新连接 / 设置 / 退出。
- 换服务器地址或快捷键：托盘右键 → “设置服务器地址…”。

常见问题
--------
- 打不开 / 白屏：先确认能上网，服务器地址默认是
  http://59.110.24.80:8787；如果服务器换了地址，在托盘菜单的
  设置里改，改完要重新登录一次。
- 快捷键没反应：可能是被别的软件占了，改一个不常用的组合
  （比如 Ctrl+Alt+Y）再试。
- 退出程序：托盘右键 → 退出。直接关窗口只是隐藏，不会退出。
